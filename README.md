# Personal Hisab

Personal-use Android हिसाब-किताब app.

## Current scope
- Cash in Hand
- Union Bank — Current Account
- Kotak Bank — Savings Account
- Sale / Maal Sold with automatic profit
- Party-wise lifetime ledger and pending
- Receive / Expense / Personal Expense / Household Expense
- Account-to-account Transfer
- Dashboard, daily and monthly reports
- Search and filters
- Backup / Restore and export
- Local persistent data storage

## Important
This repository is being used as the dedicated working repository for the Personal Hisab project. It is separate from the Luxus Collection quotation app.

The Android source project will be added here as the next project commit.
